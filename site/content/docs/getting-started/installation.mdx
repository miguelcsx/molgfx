## Python

MolGFX requires Python 3.12 or newer. Install the base package with MolFrame:

```bash
python -m pip install --upgrade molgfx
```

The package depends on `molframe>=0.4.0`. Import both at the top of molecular workflows:

```python
import molframe
import molgfx
```

## Rust

Add the facade crate and MolFrame to `Cargo.toml`:

```toml
[dependencies]
molgfx = "0.4"
molframe = "0.4"
```

Use `molgfx` rather than an internal renderer crate. The facade exposes `Scene`, `Renderer`, `rep`, `sel`, `color`, and the public command API.

## Browser requirements

The WebAssembly bindings render on a canvas you provide, through WebGPU. Use a current Chrome or Edge; Safari and Firefox need WebGPU enabled. Opening the device reports a typed error when no adapter is available.
