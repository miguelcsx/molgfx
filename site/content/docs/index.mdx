MolGFX renders a [MolFrame](https://miguelcsx.github.io/molframe/) structure as an interactive scene or a deterministic image. It is a rendering library: MolFrame reads structures and provides the selection language; MolGFX decides how they look.

<Callout type="info" title="Start with a real structure">
The quickstart uses haemoglobin (PDB 4HHB), cartoon context, and a space-filling heme pocket. It is the same workflow as the runnable [Workbench notebook](https://github.com/miguelcsx/molgfx/blob/main/examples/workbench.ipynb).
</Callout>

## What MolGFX owns

- **MolFrame**: structure input, molecular selections, and bond inference.
- **MolGFX**: scenes, representations, appearance, interaction state, rendering, and browser transport.
- **Your application**: where structures come from, when to render, and where images or widgets are displayed.

That division keeps the selection syntax consistent. Pass a MolFrame query object or its query text to a MolGFX target; start with [Writing queries and commands](/docs/commands/queries), and see the [MolFrame query reference](https://miguelcsx.github.io/molframe/docs/query-language/) for the full language.
