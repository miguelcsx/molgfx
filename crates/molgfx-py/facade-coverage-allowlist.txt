# Names the facade publishes that the Python surface does not carry, with the
# reason for each. Checked by `tests/facade_coverage.rs`; the list may only
# shrink, and an entry that stops being true fails the test.
#
# Reasons:
#   hal-seam   the device abstraction is the extension point for backend
#              authors; a program drawing a scene never names a device trait
#   gpu-layout an instance-record layout the shaders consume, not an
#              authoring type
#   provider   paged-chunk plumbing between the dataset provider and the
#              residency machine
#   internal   the interior of a machine: arenas, clipmaps, spatial indexes,
#              counters and the borrowed coordinate seam
#   trait      a dispatch interface with no single concrete value to wrap, or a
#              record only that interface produces
#   projected  a borrow over scene data, carried as an owned snapshot when a
#              caller needs it
#   flattened  a typed error the binding raises as its Python equivalent
#              (`ValueError` for a rejected argument, `CoreError` otherwise),
#              or an argument-shaped value the binding spells as the Python
#              values it is built from
#   parallel   a thread-partition knob behind the crate's own hot loops;
#              callers get the parallelism, never the scheduling
#
# A whole module is excused with a trailing `::*`.
